# Концепция: автономная mesh-сеть телеметрии и текстовой связи высокой дальности

## 1. Суть плана

Предполагается создать **собственную mesh-сеть** из устройств на базе **ESP32 + LoRa (SX1262)**, которая:

- Работает **без какой-либо инфраструктуры** (нет вышек сотовой связи, нет Wi-Fi, нет проводов).
- Передаёт **текстовые сообщения** между людьми.
- Собирает **телеметрию** с датчиков (стационарных и носимых).
- Ретранслирует данные **через промежуточные узлы** (mesh), увеличивая зону покрытия.
- Не является клоном Meshtastic, а использует **собственный протокол**, заточенный под конкретные задачи.

## 2. Ключевое отличие от рации

**Рация:**
- Тип связи: голос
- Дальность: 1–15 км (прямая видимость)
- Ретрансляция: нет (без репитеров)
- Датчики: костыль через модем
- Цена на точку: высокая (голос + модем)
- Асинхронность: нет (нужно нажать кнопку)

**Планируемое устройство:**
- Тип связи: текст + данные
- Дальность: до 15 км (в теории), через mesh — больше
- Ретрансляция: да, автоматическая
- Датчики: встроенная поддержка
- Цена на точку: низкая
- Асинхронность: да (M2M)

**Вывод:** это не замена рации. Это **автономная сеть телеметрии и текстовых сообщений для удалённых территорий**.

## 3. Целевые сценарии

- **Сельское хозяйство:** датчики влажности почвы, температуры, уровня воды на полях без GSM.
- **Трубопроводы / ЛЭП / ж/д:** мониторинг температуры, вибрации, утечек.
- **Заповедники / заказники:** трекинг животных, погодные станции.
- **Буи:** уровень воды, температура, солёность.
- **Удалённые посёлки:** короткие сообщения «всё нормально» / «нужна помощь».
- **Насосные станции:** температура воды, показания счётчиков, жёсткость воды.
- **Стационарные станции:** будка на земле / коробка на дереве.
- **Носимые устройства:** крепление на ремень (сбор температуры тела, пульса, кислорода).

## 4. Аппаратная платформа

- **Микроконтроллер:** ESP32 (S3 для стационарных, C3 для компактных).
- **LoRa-трансивер:** *SX1278* 
- **Питание:** батарея + солнечная панель для стационарных станций.
- **Автономность:** *требует подсчета*
- **Датчики:** температура, влажность, давление, *GPS/ГЛОНАСС*, уровень воды, пульс, кислород — в зависимости от сценария.
- **Внешние устройства:** краны с электроприводом, световые маячки

## 5. Протокол (собственный, не Meshtastic)

### 5.1. Маршрутизация

- **Лавинная маршрутизация** для всенаправленных (срочных или важных) сообщений
- **Прямая маршрутизация** для обычной телеметрии (таблицы маршрутов через соседей).
- **Гибрид** — как в MeshCore.

### 5.2. Обязательные подсистемы

- **Заголовок пакета:** ID отправителя, ID получателя, уровень важности, тип данных, кол-во переходов.
- **Переходы:** запись ID устройств, которые были пройдены при переходе сообщения
- **Обнаружение петель:** отброс пакетов, вернувшихся к отправителю.

## 6. Аналоги

- **MeshCore** — lightweight C++ библиотека, flood + direct routing, embedded.
- **meshcore-bare-esp32s3** — чистый ESP-IDF, нативный драйвер SX1262, BLE, шифрование.
- **ESP32-LoRa-Mesh-Server** (arn-c0de) — минималистичный скелет с SX1276.
- **LoRaMesher** — академическая библиотека с FreeRTOS, routing tables, фрагментацией.

## 7. Ограничения, которые принимаются

- **Скорость:** LoRa — 0.3–22 кбит/с.
- **Густой лес:** затухание ~25 dB, дальность падает до 1–2 км.
- **Город:** застройка режет до 1–3 км.
- **Плотная сеть:** коллизии, нужно грамотно настраивать переходы и каналы.
